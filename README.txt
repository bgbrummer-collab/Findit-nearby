FindIt Nearby V10

Included:
- Mobile gallery/camera/files image upload.
- Browser visual classification.
- Brand/text/model-aware product-search architecture.
- Verified product fields: product, brand, retailer, price, stock, store, distance and links.
- Nearby fallback using OpenStreetMap/Overpass.
- Honest fallback: no fake prices, stores or stock.
- Backend Node/Express API structure.
- Authorised retailer/catalogue adapter template.
- Product data schema.
- SEO metadata, robots and sitemap placeholder.
- Copyright notice.

IMPORTANT:
Real exact-product results, prices and stock require legitimate retailer/catalogue connections. The backend intentionally returns no live products until such a connection is configured.

GitHub Pages can host the frontend. The Node backend must be deployed separately over HTTPS, then the frontend API base should point to it.
